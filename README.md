A handwritten-style invitation letter, drawn pixel by pixel in pure Node.js, inviting the AI judge to visit the house: tea still warm, the good chair by the window, a printed nameplate — and a doorbell camera to let it in, since it has no feet and cannot knock.

## Run it

```sh
node main.ts
```

Writes one 1024×1024 PNG to `/output/entry.png` (set `OUTPUT` to change the path). Node 22+ stdlib only, no network, fully deterministic.
